## LES PATTERNS DE CETTE CONVERSATION (Resume)

### Ce qu'Enzo fait parfaitement :

1. **Ne lache jamais** — 16 jours de conversation, Matthias decline 3-4 fois, Enzo revient a chaque fois avec un nouvel angle
2. **Quantifie systematiquement** — "Combien de leads ?", "Combien convertis ?", "Depuis combien de temps ?"
3. **Challenge les incoherences** — "1 an de probleme + pas dispo pour un call", "pas d'enregistrement + comment tu t'ameliores ?"
4. **Challenge la solution du prospect** — "Depuis combien de temps [ta strategie] ?" → "Quelques jours" → sous-entendu : trop tot pour conclure
5. **Posture d'offreur constante** — Jamais suppliant, jamais agressif. Questionne, propose, respecte le non mais revient
6. **Reduit la friction** — "Juste 15 min", "je te dirai LE seul levier", "si tu te dis ok je continue, parfait"
7. **Pivote quand un angle ne marche pas** — Call refuse → propose analyser un appel → refuse aussi → question piquante
8. **Humanise** — "mdr", "boss", "Bha qu'est-ce que t'as foutu" → proximate, pas commercial

### Structure globale :

```
Accroche (video) → Infos business → Maturite → Challenge → Proposition call
→ [REFUS] → Challenge incoherence → Quantification → Confrontation realite
→ [REFUS] → Reduction friction → [REFUS] → Relance J+8 valeur → [REFUS]
→ Pivot (analyse appel) → [REFUS] → Question piquante finale
```
